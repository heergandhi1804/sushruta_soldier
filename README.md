# Sushruta's Secret Map & The Living Lancets

A browser-based educational simulation built with React, TypeScript, Vite, TailwindCSS, and Framer Motion.

## Features

- Four stages of interactive medical simulation.
- Physician scroll progression system.
- Visible consequences for every decision.
- Historical, Ayurvedic, and simulation reality layers.
- Local save/load and challenge code sharing without a backend.
- Designed for desktop, tablet, and mobile.

## Run

1. `npm install`
2. `npm run dev`

## Project structure

- `src/components/`: shared UI and controls.
- `src/stages/`: stage-specific systems and screens.
- `src/systems/`: global simulation engine and state.
- `src/data/`: datasets for patients, tools, marma points, achievements.
- `src/hooks/`: reusable hooks.
- `src/utils/`: local storage and formatting support.
